# Student Wallet Test Cases

Use demo accounts and fake transactions. Where timing or exchange rates affect the result, use the fixture described in the test and record the environment. The actual result stays blank until the case is run. Record Pass, Fail or Blocked after execution. The two features identified in issue #28 as outside the current build are marked Not implemented.
