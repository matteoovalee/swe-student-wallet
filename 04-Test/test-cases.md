# Student Wallet Test Cases

Use demo accounts and fake transactions. Where timing or exchange rates affect the result, use the fixture described in the test and record the environment. Results below distinguish Abbod's supplied 22–23 November handoff from Codex assistant executions on 23 November 2026 (Asia/Kuala_Lumpur). Blocked includes incomplete evidence; partial checks are not counted as full passes. See test-results.md for methods and raw output. The selected-month CSV export was verified through the Streamlit transaction table toolbar. Sponsor invitations (FR-10) and admin category management (FR-11) are Not implemented. Registration, part of FR-13, is not built either: the prototype has three demo accounts (student, sponsor, admin).
