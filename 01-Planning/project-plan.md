## How we work

We use Scrum in a simple form: one-week sprints, from Monday to Sunday. Every sprint has a goal and a milestone on GitHub. Tasks are issues on the project board (Todo, In Progress, Done). Every task gets its own branch and pull request, and the pull request says which issue it closes. At the end of a sprint we tag the version on main.

We talk in the group chat and meet at the Wednesday tutorial (12:00-14:00). Notes of each meeting go in 01-Planning/meeting-notes/.

## Main activities

1. Choose the system and write down why (Smart Financial, student wallet in two currencies).
2. Collect requirements: user stories, functional and non-functional requirements, a survey with international students.
3. Model: use case diagram and descriptions, architecture, ER diagram.
4. Design the screens: wireframes in Figma.
5. Build the prototype in Python with Streamlit.
6. Test: test plan, test cases, test results, traceability matrix.
7. Write the report and prepare the presentation.
